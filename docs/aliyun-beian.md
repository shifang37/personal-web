# 路线 B：阿里云服务器 + ICP 备案全套流程

> 适用场景：想让网站放在中国大陆、追求访问速度，或以后要跑后端/数据库。
> 代价：要备案，审核 1~3 周；服务器约 100 元/年起。
> 备案本身**完全免费**，任何"代备案""加急备案"都是骗钱或违规。

---

## 0. 先看时间线，心里有数

| 阶段 | 耗时 | 你能做什么 |
|---|---|---|
| 买服务器 | 10 分钟 | 立即 |
| 准备材料 + 填备案 | 30~60 分钟 | 立即 |
| 阿里云初审 | 1~2 个工作日 | 期间可能电话核实 |
| 提交管局 + 短信核验 | 24 小时内必须完成 | 收到短信马上操作 |
| 管局审核 | 1~20 个工作日（多数 5~10 天） | 等，别催 |
| **网站可以上线** | 备案通过后 | 切解析、装证书 |
| 公安联网备案 | 网站开通后 30 日内 | 补做，也要挂页脚 |

**总计：顺利的话 1 周，慢的话 3 周。** 备案期间网站不能对大陆开放访问，
所以建议**先按路线 A 用 Vercel 上线**，备案通过后再把解析切到阿里云服务器——
域名不变，用户完全无感，这是最省事的方式。

---

## 1. 买服务器：硬性条件先搞清

备案对服务器有**资质要求**，买错了就没法备案：

| 条件 | 要求 |
|---|---|
| 地域 | 必须是**中国大陆**地域（香港、新加坡等不支持备案） |
| 类型 | ECS（包年包月）或 轻量应用服务器 |
| 时长 | 购买时长 **≥ 3 个月**（按量付费 / 1 个月的不行） |
| 公网 IP | 必须有独立公网 IP |

**选哪个**

- **轻量应用服务器**（推荐）：2 核 2G / 3~5 Mbps 带宽，新用户首年约 100~160 元，
  带宽比同价位 ECS 大得多，个人站完全够。控制台简单，适合新手。
- **ECS 经济型 e 实例**：2 核 2G 约 100 元/年起，但公网带宽按量或小带宽，
  灵活性强，适合以后要装数据库/跑后端。

个人主页是纯静态站，**1 核 1G 都用不完**，重点看带宽。3 Mbps ≈ 375 KB/s，
同时 10 个人看静态页不会卡。

**镜像**：Ubuntu 24.04 或 Alibaba Cloud Linux 3 都行。想省事可以选"宝塔面板"
镜像（图形化管理），但纯静态站用 Nginx + 命令行更轻、更安全。

> ⚠️ 续费价格会明显高于首年，长期用可以一次买 2~3 年。

## 2. 备案前，材料备齐（个人备案）

| 材料 | 说明 |
|---|---|
| 身份证 | 正反面清晰照片，四角完整，不能反光/遮挡 |
| 手机号 | 本人实名，备案全程会用它接短信和电话核实 |
| 邮箱 | 常用邮箱 |
| 人脸核验 | 用**阿里云 App** 扫码核验，不用去核验点 |
| 居住证（非户籍地备案时） | 部分省份（如江苏、浙江、上海）要求在**户籍地或居住地**备案；在非户籍省份备案需提供当地居住证/社保 |
| 域名 | 已完成**实名认证**（你的 `shifang37.com` 已通过，我查过 NS 已生效） |

**几个容易卡住的点：**

1. **域名持有者 = 备案主体**。`shifang37.com` 的 whois 姓名必须和备案的身份证一致，
   否则管局直接驳回。
2. **网站名称有规则**：个人备案不能用"XX公司""XX官网""XX商城"，
   不能含"中国/国家/政府/新闻"等字样，不能是纯英文或纯数字。
   建议写：`施方的个人主页`、`某某的技术博客`。
3. **备案服务码**：在阿里云备案系统里"申请备案服务码"，选你的实例生成。
   ECS 每个实例可申请 5 个，3 个月内有效。
4. 先确认你的**省份是否支持个人备案**某些内容类型（博客类一般没问题）。

## 3. 提交备案（一步步）

1. 打开 <https://beian.aliyun.com> → 用**购买服务器的那个阿里云账号**登录
   （备案主体和服务器账号要能关联上）。
2. 点「开始备案」→ 选择「**新增备案**」（不是"接入备案"，接入是给已在别处备案的域名用的）。
3. 填**主体信息**：姓名、身份证号、证件地址（按身份证）、手机、邮箱、备案省份
   （户籍地或居住证所在地）。
4. 填**网站信息**：
   - 域名：`shifang37.com`
   - 网站名称：`施方的个人主页`（按上面规则起）
   - 网站服务内容：个人博客 / 其他（按省份选项）
   - 网站语言：中文简体
5. 选**备案服务码**：绑定你买的实例。
6. 上传身份证照片，**在线签署**《网站备案信息真实性核验单》。
7. 用**阿里云 App 扫码做人脸核验**（手机端完成，1 分钟）。
8. 提交 → 等阿里云初审（1~2 个工作日，会打你手机核实信息，**务必接**）。

## 4. 等审核期间的三件事

1. **短信核验**：材料提交管局后，你会收到工信部 `12381` 发来的短信，
   **24 小时内**必须点链接完成核验，超时会被退回重来。这一条最容易翻车。
2. **不要让域名解析到大陆服务器**。首次备案提交管局时，网站不能已经在大陆服务器上
   开通访问（管局会抽查）。你现在解析指向 Vercel（境外），通常不影响审核；
   但如果阿里云备案专员要求关站，先临时停掉首页或把解析摘掉，通过后再恢复。
   关键是保证**没有**指向阿里云 ECS 的 A 记录。
3. 期间不要改域名 whois、不要转让域名、不要给服务器降配/退订。

**查进度**：备案系统里能看到状态；也可以在 <https://beian.miit.gov.cn> 用域名查询。

## 5. 备案通过后（关键，别漏）

1. **页脚挂备案号**，必须是可点击链接到工信部：
   打开 `index.html`，把页脚里注释掉的那行取消注释：
   ```html
   <p><a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">粤ICP备00000000号</a></p>
   ```
   把号码换成你实际拿到的（如 `粤ICP备2025xxxxxx号-1`）。**必须挂在首页底部**，否则会被责令整改。
2. **30 日内做公安联网备案**：<https://beian.mps.gov.cn> 注册 →
   提交主体信息、网站信息、域名、ICP 备案号、接入商（阿里云）。
   审核通过后拿到"公网安备 xxxxxxxxxxxx 号"，同样挂页脚。
3. 然后把 DNS 切到服务器 IP（第 6 节）。

## 6. 部署到服务器

### 6.1 开放端口

- 轻量应用服务器：控制台 →「防火墙」→ 添加规则，放行 **80**、**443**（22 默认开）。
- ECS：控制台 →「安全组」→ 入方向放行 80/443。

### 6.2 登录服务器

```powershell
# 本地 PowerShell，把 IP 换成你的
ssh root@你的服务器公网IP
```

第一次连需要输密码（在控制台「重置密码」里设）。想更安全就配 SSH 密钥、关掉密码登录。

### 6.3 装 Nginx

```bash
# Ubuntu / Debian
apt update && apt install -y nginx

# Alibaba Cloud Linux / CentOS / Rocky
dnf install -y nginx

systemctl enable --now nginx
```

### 6.4 上传网站文件

在服务器上建目录：

```bash
mkdir -p /var/www/shifang37.com
```

在本机项目目录里执行（用项目自带的脚本）：

```powershell
cd C:\Users\shifang37\Desktop\personal-web
.\deploy\upload.ps1 -Server 你的服务器公网IP
```

或者手动：

```powershell
scp -r index.html assets robots.txt root@你的服务器公网IP:/var/www/shifang37.com/
```

### 6.5 配置 Nginx

把项目里的 [deploy/nginx.conf](../deploy/nginx.conf) 传到服务器：

```bash
# Ubuntu / Debian
nano /etc/nginx/sites-available/shifang37.com
# 粘贴内容后保存，然后启用
ln -s /etc/nginx/sites-available/shifang37.com /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default

# Alibaba Cloud Linux / CentOS
nano /etc/nginx/conf.d/shifang37.com.conf

# 校验并重载
nginx -t && systemctl reload nginx
```

### 6.6 DNS 切到服务器

阿里云 → 云解析 DNS → `shifang37.com`：

| 类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `@` | 你的服务器公网 IP |
| A | `www` | 你的服务器公网 IP |

**先删掉原来指向 Vercel 的 A / CNAME 记录**，同一个主机记录不能有两条冲突的解析。

### 6.7 开 HTTPS

```bash
# Ubuntu
apt install -y certbot python3-certbot-nginx
# Alibaba Cloud Linux
dnf install -y certbot python3-certbot-nginx

certbot --nginx -d shifang37.com -d www.shifang37.com
```

按提示填邮箱、同意协议，选「自动把 HTTP 跳转到 HTTPS」。
证书 90 天有效，`certbot` 会自动续期（`systemctl list-timers | grep certbot` 可确认）。

> 也可以申请阿里云的免费 SSL 证书，但个人测试证书有效期只有 3 个月且要手动续，
> 不如 Let's Encrypt 的自动续期省心。

## 7. 验收清单

在浏览器和命令行各过一遍：

```powershell
nslookup shifang37.com        # 应返回你的服务器 IP
nslookup www.shifang37.com
```

- [ ] `http://shifang37.com` 能打开（会被 301 到 https）
- [ ] `https://shifang37.com` 显示小锁，无证书警告
- [ ] `https://www.shifang37.com` 也能打开
- [ ] 页脚能看到 ICP 备案号且能点开工信部网站
- [ ] 手机 4G 流量下能打开（排除本地缓存/内网 DNS 干扰）
- [ ] 服务器重启后网站自动恢复（`systemctl is-enabled nginx` 应为 enabled）

## 8. 常见坑

**备案被驳回的典型原因**
- 网站名称不合规（带"公司""官网""博客"以外的行业词）
- 身份证照片模糊、边缘被裁、有反光
- 域名持有者姓名与备案主体不一致
- 人脸核验时环境太暗或戴帽子
- 非户籍地备案没提供居住证

**网站打不开**
- 安全组/防火墙没放行 80/443（最常见）
- Nginx 配置里的 `root` 路径写错，去看 `tail -f /var/log/nginx/error.log`
- 阿里云对未备案域名解析到大陆 IP 会拦截 → 必须备案完成后再解析
- DNS 还没生效（TTL 600 秒，等 10 分钟）

**换服务器了怎么办**
需要做「**接入备案**」（变更接入商/服务器），不能直接换 IP 了事，
否则会被抽查到备案信息不符。这一步在备案系统里提交变更，比首次备案快。

**个人备案能做什么**
- ✅ 个人博客、作品集、简历、开源项目主页
- ❌ 电商、付费内容、放联盟广告盈利、论坛（需专项审批）
- ❌ 新闻、出版、教育、医疗、药品等（需前置审批）

## 9. 什么时候值得走这条路

- 大陆访问速度是硬指标（比如用来求职、给客户看）
- 需要后端：接口、数据库、文件上传
- 需要在国内做 SEO、被百度快速收录
- 只是展示个人主页 → **路线 A（Vercel）就够了，别折腾备案**

两条路线可以并存：先用 Vercel 上线，备案批下来再切阿里云，中间随时可回退。
